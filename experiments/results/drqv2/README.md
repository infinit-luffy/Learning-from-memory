「学会」= 最后一次 eval > 200；walker-walk 的随机策略约 20–24 分。

## 读这张表必须注意的三件事

### 1. 最后一次 eval 在 475K agent step，不是 500K

DrQ-v2 的训练循环在 `global_step == 500000` 时先退出、后 eval。与 W1.2 的
500K 点比较时要么取 475K 对 475K，要么改用 final-checkpoint 重测口径。

### 2. walker_walk 的失败是**双峰**，均值是误导性统计量

失败形态一律为**从第 0 步就不动**，不是学到一半崩。easy 臂 9 个 seed 分成
`{21,28,28,28,29,30,33}` 与 `{789, 870}` 两簇 —— 学会的那两个与 TD-MPC2 的
853.7 相当。

→ **DrQ-v2 在带干扰的 walker 上不是学不会，而是大概率起不来。**
论文应报「学会率 + 学会者的分数」两个数并画双峰，不要报 mean ± sd。

同一格 TD-MPC2 是 3/3、853.7 ± 89.0 —— model-based 在干扰下**不仅更强，
更重要的是更可靠**。

### 3. clean 的 2/6 失败是 DrQ-v2 的已知性质 —— 有其官方数据为证

`third_party/drqv2/curves/dmc_walker_walk.csv`（作者随仓库发布的 10-seed 曲线）
@1M frames：

```
950  962  949  **24**  960  956  960  **29**  910  968
```

**官方自己就有 2/10 个 seed 卡在 24 / 29 分**，形态与我们完全一致。
我们的 2/6 与之相容。**不是我们的集成或配置问题。**

（唯一的配置覆盖是 `num_train_frames` 1M vs 官方 1.1M，而该参数只决定何时停：
`stddev_schedule` 按 global_step 走、`num_seed_frames` 独立，
不可能导致「从第 0 步就不学」。已排除。）

### 4. 用官方数据扩充基线后，easy 的效应显著

| | 失败 / 总数 | 失败率 |
|---|---|---|
| 官方 clean（作者发布） | 2 / 10 | 20% |
| 我们 clean | 2 / 6 | 33% |
| **合并 clean** | **4 / 16** | **25%** |
| **我们 easy** | **7 / 9** | **78%** |

```
Fisher 单侧 p = 0.016   **显著**
```

→ **背景干扰把 DrQ-v2 在 walker 上的失败率从 ~25% 推到 ~78%。**

此前只用我们自己的 clean（n=6）当基线时 p = 0.119，做不出显著性；
官方的 10-seed 曲线是免费的基线扩充。
（过程中还曾在 easy 0/5 的中间态得到 p = 0.046，那个数**已作废**
—— 第 6 和第 8 个 seed 都学会了。）

### 5. 判定失败必须看完整曲线

`none s4` 在 200K frames 时只有 19 分（与失败者无异），500–600K 才起飞，
最终 879。真正失败的 s3/s5 则全程 20–26、零上升趋势。
